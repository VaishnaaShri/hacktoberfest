Problem Statement
The Problem:
Students regularly share sensitive documents such as Aadhaar, marksheets, PAN cards, and ID photos with xerox shops through WhatsApp, email, or USB drives. These files may remain on shop computers even after printing, creating a risk of data leakage, misuse, and identity theft

Why We Chose This Problem
We chose this problem because it is common, relatable, and often overlooked. Students need a simple and secure way to print sensitive documents without losing control of their personal data. Our solution addresses this everyday privacy gap using AI and cybersecurity.

Solution
PrintLeak Shield is a secure document-printing system that lets students upload sensitive documents through a QR-based portal instead of sharing them directly with xerox shop computers. The system uses AI to identify sensitive information, enables secure one-time printing, and automatically removes the digital copy after printing.

Key Features

QR-Based Secure Upload: Students upload documents without using WhatsApp or USB drives.

AI Privacy Detection: Identifies sensitive documents and personal information such as Aadhaar numbers and addresses.

One-Time Printing: Generates a temporary print code that can be used only once.y

Auto-Delete & Receipt: Digital files expire after printing, and students receive a deletion confirmation

Leftover File Scanner: Detects potentially sensitive files already stored on shop computers for cleanup.
